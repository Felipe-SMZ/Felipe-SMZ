## Projetos

### [Produtos API](https://github.com/Felipe-SMZ/produtos-api)
API REST completa para gerenciamento de produtos, construída com arquitetura MVC em camadas.

**O que foi implementado:**
- CRUD completo com os 4 verbos HTTP (GET, POST, PUT, DELETE)
- Autenticação e separação de responsabilidades com DTOs
- Validação de dados com Bean Validation e mensagens de erro claras
- Tratamento global de exceções com `@RestControllerAdvice`
- Testes unitários com JUnit 5 e Mockito (6 cenários cobertos)
- Containerização completa com Docker e Docker Compose

`Java` `Spring Boot` `Spring Data JPA` `MySQL` `Docker` `JUnit 5` `Mockito` `Maven`

---

### [FatecRide](https://github.com/Felipe-SMZ/fatecRide)
Sistema de caronas colaborativas desenvolvido como Projeto Integrador na FATEC. Conecta estudantes que oferecem e buscam caronas, promovendo economia e sustentabilidade na comunidade acadêmica.

**Minha contribuição:**
- Desenvolvimento do backend com Java e Spring Boot
- Modelagem e persistência de dados com Spring Data JPA e MySQL
- Autenticação de usuários com JWT
- Integração com frontend React

`Java` `Spring Boot` `React` `JavaScript` `MySQL` `MongoDB` `Node.js`
